Send schedules

Share with a code

Export selected schedules as a code you can send in a message. Your friend can import it here. All schedule data is inside the code; nothing is stored in the cloud.

Choose schedules to export

Compact exports omit course codes and sections, and shorten instructor names to surnames. Your saved schedules keep all details. Copy the full code and have your friend refresh this app to import it. Older codes still work.

Import a friend’s schedules

Paste the full code, including its special characters. New names import automatically. Identical names and timetables are skipped. For the same name with a different timetable, choose Keep both, Replace or Keep old one.
